# Stack logos

From [Simple Icons](https://simpleicons.org) 16.36.0, released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The marks remain trademarks of
their owners and are used only to name the tools this project is built with.

Only each icon's path data was kept. It was checked to contain nothing but path commands and
numbers, then rebuilt into a plain SVG drawn in `currentColor`, so the logos follow the demo's
light and dark themes.
